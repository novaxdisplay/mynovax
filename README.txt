ЧТО НОВОГО В V10
В фирменном КП максимальное и среднее потребление теперь указаны вместе,
на один экран, без умножения на тираж. Неизвестное потребление не выдумывается.
Структура исходного шаблона не изменена; закупка и наценка остаются закрытыми.

ABSEN P2.5 и P1.86: готовые кабинеты включают БП, принимающую карту NovaStar,
магниты, проводку и внутренний крепёж по подтверждению владельца.
Отдельно эти детали не закупаются и не оплачиваются повторно.
Наружная рамка: профиль 25×90, соответствующие четыре уголка,
соединители длинных сторон и железные вертикальные опоры по размеру.
Количество железа: столбцы кабинетов + 1, раскрой с припуском и пропилом.
ABSEN P1.53 640×480 и KLCOB P1.2 600×337.5: готовый корпус включён;
в закупке только кабинеты и процессор NovaStar, без второй рамы/крепежа.
Монтаж остаётся отдельной редактируемой работой, не бесплатным оборудованием.
Прежний запас готовых кабинетов P2.5/P1.86 сохранён и редактируется отдельно.

KLCOB P1.2 — точная модель из прайса, которую владелец имел в виду под P1.25.
ABSEN P1.53: 444×314 px по последнему уточнению владельца, не по паспорту
производителя. Значения показаны в полях и остаются редактируемыми.
Для P2.5/P1.86 предзаполненные 128×192 / 172×256 пока не подтверждены:
проверьте паспорт выбранной панели, поправьте числа и поставьте галочку.
Для неизвестной пиксельной сетки укажите px одного кабинета и подтвердите
по его паспорту. Подтверждение привязано к модели и сбрасывается при правке.
Размер в миллиметрах / номинальный шаг не заменяет паспортное разрешение.
Выбор процессора NovaStar проверяет одновременно общий пиксельный предел,
выходную ширину/высоту и целую схему Ethernet-зон, до 650000 px/порт
для обычного 2D, 8bit, 60 Гц. Кабинет / регион карты между портами не делится.
План предварительный: минимальность среди всех нестандартных разводок
не обещается. При нехватке портов берётся подходящая доступная модель.
Подтверждение вручную не разрешает превышать известные пределы процессора.

Outdoor модульный: по умолчанию M4/1417S, строго с суффиксом S.
Покупка поштучная: цена упаковки / 500, четыре на рабочий модуль.
ULTRA не имеет цены этого exact SKU: не подставляется M4/1417 без S;
выберите допустимый другой артикул явно или введите свою цену.

Автосохранение показывает конкретную причину сбоя отдельно от ошибок сметы.
Неподтверждённая смета сама по себе не означает, что проект не сохранился.
Замечания сгруппированы по экрану; «Открыть расчёт» раскрывает нужную
карточку и переводит к проблемной строке или полям разрешения кабинета.

СОХРАНЁННЫЙ РАСЧЁТ V9
Железный профиль LEDART 5011 длиной 3 м автоматически дозакупается
для наращивания длинных вертикальных полос. Раньше такая полоса
блокировала расчёт; теперь смета показывает целые основные профили
и дополнительные профили на доборы.

Обычная модульная сборка: полос = столбцы модулей + 1;
длина полосы = фактическая высота + 10 мм припуск.
Целые неотрезанные хлысты используются без фиктивного пропила.
Короткие доборы режутся с учётом пропила 3 мм; покупаются целые хлысты.
Для строки применяются выбранные припуск и пропил.
В смете указаны длина добора, количество основных/дополнительных
хлыстов и стыков. Это закупочный расчёт, не проверка прочности сварки.
Стоимость сварки/крепления при необходимости задайте в своих работах.
Новых выдуманных цен на соединение железного профиля не добавлено.

Примеры: 21 полоса по 3082 мм -> 21 основной + 1 дополнительный = 22.
3 полосы по 4010 мм -> 3 основных + 2 дополнительных = 5.
Без припуска и пропила идеальные 3 полосы по 4000 мм дали бы 4,
но существующие припуск и пропил нельзя игнорировать при закупке.
Число «5» не применяется ко всем размерам как фиксированная добавка.

Правило применяется при LEDART и в Mixed для этого профиля LEDART.
ULTRA, другие железные артикулы и алюминиевая рамка не изменены.
Длина закупаемого хлыста, количество и цена по-прежнему редактируются.
Ручное количество сохраняется; «Авто» возвращает новый расчёт.
Старые проекты поддерживаются; V8 не перезаписан.

СОХРАНЁННЫЕ УЛУЧШЕНИЯ V8
1. Контактная страница КП: премиальные блоки телефона, Instagram и сайта
   в фирменных серебристо-синих цветах. Телефон крупный и кликабельный.
   Пустые необязательные контакты не выводятся. Остальные страницы сохранены.
2. Кнопка карточки раскрывает и скрывает расчёт того же экрана.
   Сворачивание не удаляет экран, количество, ручные цены и правки КП.
3. P3.91 убран из обычных Outdoor. Арендный P3.91 сохранён.
4. LEDART автоматически выбирает оптовый или дилерский прайс.

КАК ВЫБИРАЕТСЯ ПРАЙС LEDART
Порог подтверждён владельцем: закупка материалов и оборудования
ПО ВСЕМУ КП, с учётом количества одинаковых экранов.
До 1 000 000 ₸ включительно — ОПТОВЫЙ; выше — ДИЛЕРСКИЙ.
Наценка, скидка, монтаж, доставка и другие работы в порог не входят.
Закупка для сравнения сначала оценивается по ОПТОВЫМ ценам.
После выбора дилерского прайса его более низкий итог не переключает
прайс обратно: это предотвращает циклические пересчёты возле порога.
Полная себестоимость и цена клиенту по-прежнему включают выбранные работы.
Показатель закупки для порога и применённый прайс выводятся отдельно.

В строках можно изменить, входит ли позиция в закупку для порога.
Материалы и оборудование включены по умолчанию; монтаж/доставка исключены.
Свои позиции исходно считаются закупкой. Для своих работ снимите этот флаг.
Отключённая из сметы позиция не участвует ни в сумме, ни в пороге.
Ручная цена и количество сохраняются; наценка не влияет на выбор прайса.
В Mixed предложения LEDART используют тот же выбранный уровень цены;
ULTRA не получает фиктивной скидки. Сравниваются только допустимые аналоги.
Если в применяемом прайсе нет точной модели/цены, она не подменяется
другим прайсом молча: выберите модель с ценой или задайте её вручную.
